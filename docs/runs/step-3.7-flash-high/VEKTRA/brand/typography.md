# VEKTRA Typography

**Monospace:** IBM Plex Mono  
**Sans-serif:** Space Grotesk  
**CDN:** 
- `https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600;700&family=Space+Grotesk:wght@300;400;500;600;700&display=swap`

## Rationale

**IBM Plex Mono** was chosen because it is a developer-grade monospace designed by IBM — it carries the authority of technical documentation without feeling decorative. At display sizes it becomes architectural: each glyph is a vessel for signal. It suits VEKTRA because the product itself IS a code graph; letting code typeface into the identity is not a gimmick, it is an honest representation of the medium.

**Space Grotesk** was chosen because it is a contemporary grotesque that retains warmth through slightly irregular proportions. Unlike Helvetica or Inter, it has character at every weight — tight and purposeful at 11px, commanding at 72px. It bridges the gap between the technical and the editorial without leaning into either SaaS calibration or gallery pretension.
