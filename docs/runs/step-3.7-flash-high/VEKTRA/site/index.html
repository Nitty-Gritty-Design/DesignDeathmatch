001 — About

What it is

VEKTRA is not a DAW. It is not a plugin. It is closer to a language — a way of thinking about time, signal, and form simultaneously.

Electronic composers, installation artists, interaction designers, and researchers use VEKTRA to build things that behave, not just things that look. Every parameter is inspectable. Every patch is forkable. Everything is live.

"The inside of a Teenage Engineering OP-1 if it were designed by a brutalist architect."

— Designer comment, Leipzig 2019
002 — How it works

Three core concepts

01

Unified graph

Audio nodes, visual parameters, and logic branches share one graph. A frequency change can drive a shape. A gesture can rewrite a patch. There is no import / export barrier between signal and form.

02

Explicit time

Time is not hidden inside a transport bar. It is a first-class parameter — sample-accurate, inspectable, and reversible. Loop, scrub, or branch based on live data.

03

Live inspect

Every value can be read, modified, and animated in real time. No renders. No bounces. Change the system while it runs and watch the result resolve on the next sample.
