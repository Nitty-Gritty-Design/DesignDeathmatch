What it is

VEKTRA is a software environment where sound, motion, and code are treated as a single medium. It is used by electronic composers, installation artists, interaction designers, and researchers who want to make things that behave, not just things that look. It is not a DAW. It is not a creative suite. It is not a plugin. It is closer to a language — a way of thinking about time, signal, and form simultaneously.

How it works

Unified Signal Graph

All parameters exist in a single inspectable graph where audio frequencies drive visual amplitudes, LFOs modulate particle systems, and envelopes shape both sound and form simultaneously.

Live Code Editing

Modify your patch in real time with immediate feedback. Every change propagates through the system like a signal through a circuit — no recompiling, no restarting, just pure live evolution.

Generative Output

Create systems that generate endless variations. Set rules, introduce controlled randomness, and watch as your instrument produces behaviors that surprise even its creator.

Who uses it

Electronic Composer

Creates evolving soundscapes where timbre shifts in response to generative visual patterns, blurring the line between audio synthesis and visual composition.

Installation Artist

Builds reactive environments where audience movement alters both sonic and visual elements through a shared parameter space.

Creative Developer

Extends the system with custom nodes while benefiting from the unified signal framework — treating DSP and graphics as complementary aspects of the same computation.
