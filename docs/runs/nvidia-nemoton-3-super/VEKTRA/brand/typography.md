# VEKTRA Typography Selection

## Primary Typeface Pairing

### Monospace: Space Mono
**Rationale for VEKTRA:** Space Mono bridges the technical and artistic worlds that VEKTRA inhabits. Its geometric precision with subtle humanist touches makes it feel like code that's meant to be seen and appreciated, not just executed. Unlike purely mechanical monospaces (like JetBrains Mono or Fira Code), Space Mono has enough character to work at large display sizes as a headline treatment — exactly what the brief suggests for a company whose product is code. The slightly widened proportions and open counters maintain readability even when used for extended technical documentation, while its distinctive appearance signals that this is a tool for creators who see beauty in structure.

### Sans Serif: Inter
**Rationale for VEKTRA:** Inter was chosen for its exceptional neutrality and technical precision without sterility. As VEKTRA's interface typeface, it needs to recede to let content shine while maintaining absolute clarity at small sizes — Inter excels at 11px rendering on screen. Its open-source nature and extensive language support align with VEKTRA's ethos of accessibility and forkability. Unlike more geometric sans serifs that can feel cold, Inter maintains warmth through subtle design details, making it suitable for both the technical documentation and poetic copy that defines VEKTRA's voice.

## Type Scale
VEKTRA's typographic system spans from 11px (label/caption) to 80px (hero display), with editorial range and generous line heights.

### Space Mono (Monospace)
- 11px: Regular - Letter spacing: -0.5px, Line height: 1.4 (labels, captions, code inline)
- 13px: Regular - Letter spacing: -0.5px, Line height: 1.5 (footnotes, fine print)
- 15px: Regular - Letter spacing: -0.5px, Line height: 1.6 (body text in code contexts)
- 18px: Medium - Letter spacing: -0.5px, Line height: 1.7 (subsection headers, code blocks)
- 24px: SemiBold - Letter spacing: -0.5px, Line height: 1.8 (section headers)
- 32px: Bold - Letter spacing: -0.5px, Line height: 2.0 (subsection titles)
- 48px: Bold - Letter spacing: -0.5px, Line height: 2.2 (section titles)
- 64px: Bold - Letter spacing: -0.5px, Line height: 2.4 (hero subsection)
- 80px: Bold - Letter spacing: -0.5px, Line height: 2.6 (hero display)

### Inter (Sans Serif)
- 11px: Regular - Letter spacing: -0.25px, Line height: 1.4 (labels, captions, UI elements)
- 13px: Regular - Letter spacing: -0.25px, Line height: 1.5 (footnotes, fine print)
- 15px: Regular - Letter spacing: -0.25px, Line height: 1.6 (body text)
- 18px: Medium - Letter spacing: -0.25px, Line height: 1.7 (subsection headers)
- 24px: SemiBold - Letter spacing: -0.25px, Line height: 1.8 (section headers)
- 32px: Bold - Letter spacing: -0.25px, Line height: 2.0 (subsection titles)
- 48px: Bold - Letter spacing: -0.25px, Line height: 2.2 (section titles)
- 64px: Bold - Letter spacing: -0.25px, Line height: 2.4 (hero subsection)
- 80px: Black - Letter spacing: -0.25px, Line height: 2.6 (hero display)

**Usage Notes:** 
- Space Mono is used for all code displays, terminal elements, and as a display typeface for headlines that benefit from its technical character
- Inter is used for all body text, UI labels, and headlines where maximum readability is prioritized
- Both typefaces maintain consistent vertical rhythm through carefully calibrated line heights
- Letter spacing adjustments improve legibility at both small and large sizes
