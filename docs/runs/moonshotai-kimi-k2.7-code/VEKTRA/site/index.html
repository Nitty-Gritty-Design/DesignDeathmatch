01

What it is

Most tools divide the world into picture, sound, and code. VEKTRA treats them as one continuous signal graph. You describe a system: oscillators, cameras, functions, and renderers. Then you let it run.

It is not a DAW. It is not a creative suite. It is a language for time, signal, and form — used by electronic composers, installation artists, interaction designers, and researchers who want their work to behave rather than merely appear.

02

How it works

Graph

Nodes, not tracks

Everything is a node: audio oscillator, video buffer, math function, MIDI event. Connect outputs to inputs. The graph is the score.

Signal

Time is explicit

No hidden playhead. Time is a signal you can scale, modulate, sample, and feedback. Events are scheduled with sample-accurate precision.

Form

Everything inspectable

Hover any wire to see its value. Fork a patch mid-performance. Every parameter is addressable, every state is reversible.
