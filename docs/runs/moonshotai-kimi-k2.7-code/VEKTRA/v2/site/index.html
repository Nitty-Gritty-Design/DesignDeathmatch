01

What it is

Most tools divide the world into picture, sound, and code. VEKTRA treats them as one continuous signal graph.

You describe a system: oscillators, cameras, functions, renderers. Then you let it run. It is not a DAW. It is not a creative suite. It is a language for time, signal, and form — used by composers, installation artists, and interaction designers who want their work to behave rather than merely appear.

Time is explicit. Every wire carries a value. Every parameter is addressable. Every state is reversible.

02

How it works

Three core concepts. Everything else is a combination.

01

Nodes, not tracks

Everything is a node. Audio oscillator. Video buffer. Math function. MIDI event. Connect outputs to inputs. The graph is the score.

Graph
02

Time as signal

No hidden playhead. Time is a signal you can scale, modulate, sample, and feed back. Events are scheduled with sample-accurate precision.

Signal
03

Everything inspectable

Hover any wire to see its value. Fork a patch mid-performance. Every state is a parameter you can address from anywhere else in the graph.
