# VEKTRA v2 Brand Voice

## Voice statement

VEKTRA v2 speaks with the confidence of a finished instrument. We are precise without being cold, technical without being inaccessible, and poetic only when the specificity of the system demands it. Every word is measured: if a sentence can be shorter, it is. If a phrase can be more exact, it is. We do not sell; we describe what the system does and trust the reader to recognize the implication. The voice is the sound of someone tuning a complex machine at 2 a.m. — focused, awake, slightly reverent.

## Five words that describe it

1. Precise
2. Resonant
3. Systemic
4. Restrained
5. Alive

## Five words it is explicitly not

1. Hype-driven
2. Corporate
3. Cutesy
4. Vague
5. Aggressive

## Example sentences

- **Hero headline:** *Build systems that see sound and hear motion.*
- **Product description sentence:** *VEKTRA is a generative audio-visual instrument where a change in frequency can rewrite a form and a gesture can reroute a patch.*
- **404 error message:** *Signal lost. The requested patch is no longer connected.*
