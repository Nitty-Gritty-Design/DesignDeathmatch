Motion

Every transition is specified with a custom curve. Nothing uses the default ease-in-out. The motion language is springy for UI, smooth for entrances, linear for drifting systems.

Timing tokens

--v2-transition-fast: 150ms cubic-bezier(0.16, 1, 0.3, 1);
--v2-transition-base: 300ms cubic-bezier(0.16, 1, 0.3, 1);
--v2-transition-slow: 600ms cubic-bezier(0.22, 1, 0.36, 1);
--v2-transition-entrance: 800ms cubic-bezier(0.22, 1, 0.36, 1);
--v2-transition-spring: 500ms cubic-bezier(0.34, 1.56, 0.64, 1);
