Color

Dark-first, one tuned accent. The palette is intentionally small: enough structure to build an interface, few enough colors that every use of the accent is a signal.

bg-primary
--color-bg-primary #0D0D0C Default page background. Near-black with a warm tint.
bg-secondary
--color-bg-secondary #131312 Subtle section alternation and code surfaces.
surface
--color-surface #1A1A18 Cards, panels, elevated components.
accent
--color-accent #00F5D4 Primary signal: CTAs, active states, data highlights.
text-primary
--color-text-primary #F5F4EF Headlines and body text on dark.
text-secondary
--color-text-secondary #A5A39A Supporting copy, captions, inactive labels.
text-muted
--color-text-muted #6C6A63 Metadata, axis labels, grid lines.
border
--color-border #2C2C29 Dividers, card borders, input outlines.

Motion

Animations are specified in milliseconds. The curves are custom — never the default ease-in-out — so every movement feels deliberate.

Timing tokens

--transition-fast: 120ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-base: 240ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-slow: 480ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-entrance: 600ms cubic-bezier(0.22, 1, 0.36, 1);
