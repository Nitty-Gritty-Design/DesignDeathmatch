Color Tokens

VEKTRA's visual identity relies on near-black surfaces, structured borders, and a single high-frequency **Acid Lime** accent that represents voltage clipping and data locks.

Background Primary --color-bg-primary

Primary canvas backdrop. Deep warm charcoal, avoiding pure #000000 to maintain texture.

Background Secondary --color-bg-secondary

Secondary sections, code editor panels, and sidebars. Provides depth contrast.

Surface Container --color-surface

UI button backdrops, input elements, card container layers, and badges.

Electric Accent --color-accent

Acid Lime. Repesents frequencies, signals, active routing points, and selections.

Accent Dim --color-accent-dim

Dimmed accent color. Used for shadow glow layers, subtle borders, and keypress responses.

Text Primary --color-text-primary

High-contrast headlines, labels, numbers, and primary button labels.

Text Secondary --color-text-secondary

Paragraph body copy and secondary menu navigation labels.

Border Technical --color-border

Divider lines, grid boundaries, card borders, and signal paths.

Motion & Transitions

VEKTRA's animations behave with physical precision. We define transitions in milliseconds, using ease-out exponential curves.

Custom Easing Curves

Defined as tokens in tokens.css

  • --ease-in-out-sine: cubic-bezier(0.37, 0, 0.63, 1)
