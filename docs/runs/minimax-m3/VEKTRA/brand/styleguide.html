Color

All values are defined as CSS custom properties in tokens.css. Every other file uses var(--*). No exceptions.

--color-bg-primary #0E0E0C Page background. Never #000.
--color-bg-secondary #161613 Section / card surface.
--color-surface #1D1D18 Raised UI, input fields.
--color-accent #FF5C1F Signal Amber. Use sparingly.
--color-accent-dim #B83F12 Hover / disabled on accent.

--color-text-secondary #B5B2A8 Captions, secondary.
--color-text-muted #6B6960 Labels, metadata, axis ticks.
--color-border #2A2A24 Default hairline.

05

Motion

Timing is specified in milliseconds, by someone who thinks about time at the sample level. Five durations, four easings.

--dur-1120ms
--dur-2220ms
--dur-3360ms
--dur-4600ms
--ease-out-backtactile hover
signal pulse1.8s · infinite
live indicator

All transitions use tokenized easings. --ease-out-snap for entrances, --ease-in-out for pulses, --ease-out-back for tactile feedback. The system is prefers-reduced-motion-aware.
