All values are CSS custom properties in tokens.css. Every other file uses var(--*). The accent is reserved for "the signal." Use it sparingly.

03

Logo

A precise Λ — two stroke lines meeting at an apex, with a small filled circle marking "the moment." The dot is the only element in accent. The geometry is on a 1:1 grid; the mark and the wordmark share a baseline rule.
